# Program Perencanaan Umroh

This project is a comprehensive SPA (Single Page Application) for planning and managing Umroh pilgrimages, built with React, Vite, Tailwind CSS, and Supabase.

## Features

- **Dashboard**: Main interface for managing pilgrimage tasks.
- **Dark/Light Mode**: User-preference-based theme switching.
- **Umroh Guide**: Step-by-step instructions (Ihram, Tawaf, Sa'i, Tahallul) with Arabic/Latin prayers.
- **Prayer Bank**: Collection of essential prayers for the pilgrimage.
- **Cost Estimator**: Tool to estimate travel expenses.
- **GPS Navigation**: Mockup for tracking important sites.
- **Checklist**: Preparation task management.
- **Authentication**: Secure login/registration via Supabase.

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Router**: TanStack Router
- **Styling**: Tailwind CSS
- **Backend/DB**: Supabase
- **Icons**: Lucide React
